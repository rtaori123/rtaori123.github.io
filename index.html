Linking parts to the engines they fit

Problem
Dealers find parts by engine model, but thousands of parts weren't linked to the engines they fit. An automated match looked like it could fill the gap.
What I found and fixed
One engine maker reuses serial-number ranges across different models. That made 34,000 serial-only matches wrong, and one engine was linked to 12 models. I rebuilt the matching so that serial range, horsepower and model name all have to agree, and I put borderline cases in a separate list for review.
  • SQL
  • Python
  • Data quality
  • Excel
50,000+checked part-to-engine links ready for a bulk upload

Why some parts keep selling and others fade

Problem
Within a single product line, some parts grow while others decline, and nobody knew why.
What I built
A reusable tool that scores about 30 possible factors per part (price compared with the engine maker's, age of the engines it fits, how many maker part numbers it replaces, and more). It then tests which factors actually predict sales, each time leaving out the part being predicted. I ran it on fuel pumps, oil filters and gas filters, and I reported where a pattern did not carry over from one product line to another.
  • Python
  • Statistics
  • Regression
  • SQL
3 product linesFilters follow engine age; fuel pumps follow price
